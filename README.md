# SG-Vibe 🎵

SG-Vibe is a browser-based music player built using **HTML, CSS, and JavaScript**. The project focuses on creating an interactive music streaming-style interface with playlist navigation and functional audio controls.

## 🎧 Features

* ▶️ Play and pause songs
* ⏮️ Previous song control
* ⏭️ Next song control
* 🔊 Volume control
* 🔇 Mute and unmute
* 🎵 Displays the currently playing song
* 📂 Plays songs from a local song folder
* 🎶 Multiple playlists/albums
* 🖱️ Interactive playlist selection
* 🎨 Music streaming-style user interface
* 📱 Front-end focused project built without a backend

## 🛠️ Technologies Used

* **HTML5** — Structure and layout
* **CSS3** — Styling and user interface
* **JavaScript** — Audio controls, playlist interaction, DOM manipulation, and application logic

## 🚀 How to Run

1. Clone or download this repository.
2. Make sure the songs and image assets are placed in their respective folders.
3. Open `index.html` in a browser.
4. Select a playlist and start playing music.

No backend or database is currently required.
